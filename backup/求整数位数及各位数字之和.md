# 求整数位数及各位数字之和 😸 :
## 完整代码 
```c
#include<stdio.h>
int main()
{
	int n,weishu,sum = 0;
	scanf("%d",&n);
	while(n > 0)
	{
		sum = sum + n % 10;
		n = n / 10;
		weishu = weishu + 1;
	}
	printf("%d %d",weishu,sum);
	return 0;
}
```

#  总结 ：



## 技巧
### `sum = sum + n % 10`用来求个位是什么数
### 得到个位数之后把个位数加进sum里，然后再用`n = n / 10`将个位数去除，最后`weishu = weishu + 1` 记录位数

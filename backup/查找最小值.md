# C语言中的最小值查找 🐰 

```c
#include <stdio.h>

int main(void)
{
    int n;
    int num1;
    int MIN;

    scanf("%d", &n);
    scanf("%d", &num1);

    /* 将第一个数字作为当前的最小值 */
    MIN = num1;

    for (int i = 1; i < n; i++)
    {
        /* 每次读取后立即进行比较 */
        if (num1 < MIN)
        {
            MIN = num1;
        }

        scanf("%d", &num1);
    }

    printf("min = %d", MIN);

    return 0;
}
```
# 总结
> ## 在代码中，我将最开始的num1存入在MIN里，接着更新num1的值，再将跟新后的num1的值和MIN比较，若比MIN小就取代！
